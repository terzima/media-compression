# Provenance

Project-authored code is MIT. Dependencies retain their own licenses. The owner's explicit direction authorizes reuse of their Glyph work; no blanket license grant is assumed for third-party contributions.

Reviewed local reference material (not a runtime dependency): image sweep/review scripts, audio build_package.py, audition.html, blind.html, compact_m4a.py, and blind-statistics.js/tests. They are coupled to private layouts, manifests and campaigns. This implementation adapts candidate-from-original generation, output-hash deduplication, transparency comparisons, verified caching, staged export, and exclusive playback behavior. It does not copy whole source files, data, rendered comparisons, source identifiers, private manifests or Git history.

The established codecs implement compression algorithms. Newly authored orchestration and UI use the references as design evidence. Historical Glyph savings and Apple AAC scores are not validation of this backend. ViSQOL, ABX statistics and the custom M4A parser are deferred.

Public tests generate synthetic images and sounds. Released files must stand alone without owner-machine paths. Dependency source revisions/checksums and notices are recorded separately.
