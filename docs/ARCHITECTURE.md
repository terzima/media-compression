# Desktop architecture

The React GUI holds selections and persists the visible last-used custom form. It invokes narrow Tauri commands with opaque imported/candidate identifiers. Native file pickers and the backend own filesystem access. No command accepts arbitrary executable names or shell text. The CSP restricts assets to local resources; only the backend-controlled workspace is exposed through the asset protocol. There is no runtime account, upload, analytics, or updater integration.

The Rust engine probes/hash-checks originals, validates a full study before queueing, runs at most two processing jobs, and isolates image decoding/metrics in a separate worker. Image operations are serialized to bound large-image memory; pixel processing has a 50-megapixel/20,000-pixel-axis limit and color transforms use small scratch tiles. Every option encodes from the original. Duplicate output hashes retain every requested setting. Worker/helper hashes and engine version participate in cache keys. Cache hits require a versioned record with matching key/settings, a metadata checksum, output size and SHA-256; corrupt records/results are recompressed. Workspace locking prevents multiple processes deleting each other's temporary work.

Cancellation marks queued work immediately and terminates active process groups (Unix) or jobs (Windows). A drop guard reaps processes on error. Desktop exit rejects new helpers and terminates active Unix process groups; Windows kill-on-close jobs terminate their process trees. Completed candidates survive cancellation and failures. The startup clears abandoned work; verified persistent cache records remain until Clear workspace. Audio PCM is disk-backed, seekable floating point rather than held entirely in web memory. Superseded playback preparation is canceled. Switching candidates preserves the same source timeline; choosing another source resets playback and its loop. Disk capacity is checked before decoding and export; write failures are reported honestly.

Images apply EXIF orientation. Lossy encodes use sRGB; lossless optimization keeps rendering-critical metadata and verifies decoded source pixels. PNG gamma/chromaticity and RGB/gray ICC profiles drive preview conversion through Little CMS. Lossless WebP carries a supported RGB profile. Unsupported CMYK/precision/HDR/gray-profile conversion combinations return an explanation. SSIM uses two matching composites; alpha errors are measured separately. Small-image/unavailable SSIM never invalidates otherwise valid output.

FFmpeg probes/encodes/decodes audio using direct argument arrays and bundled components. Preserved sample rates depend on codec support; Opus uses 48 kHz. Samples/channels are checked after decoding; timing differences above one codec frame are rejected, and smaller codec-boundary differences are reported. FLAC supports 16-/24-bit integer inputs and decoded PCM equality is checked. Native Rodio playback uses one device/player and a shared volume, seek and loop; version switching samples the backend timeline after the comparison PCM is ready.

Export copies verified candidates to a temporary file on the destination filesystem, syncs it, then persists without replacing a file. Collisions get numeric suffixes. Folder imports retain relative parent structure. Canonical-parent checks reject symlink escapes. Original hashes are checked again. Export status and processing status are separate; completed exports remain visible after a later failure. Reports schema version 1 contain requested settings, actual bytes/properties/diagnostics, hashes, relative names, errors, and codec versions; private source/cache paths are removed.
